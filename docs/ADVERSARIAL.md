## 4. How to run things

In this cloud container, Node's `fetch` uses the proxy only with `NODE_USE_ENV_PROXY=1` (CLAUDE.md).

| What | Command |
|---|---|
| Lint, typecheck, unit tests | `pnpm check` (10/22 at b01fa7f: 646 passed, 1 skipped) |
| Production build | `pnpm build` |
| Local server | `NODE_USE_ENV_PROXY=1 pnpm start` |
| e2e locally | `pnpm build`, then `pnpm exec playwright test` (it starts `pnpm start -p 3100` itself: `playwright.config.ts`) |
| e2e against prod | `BASE_URL=https://between-two-tombstones.vercel.app pnpm exec playwright test`. The outage tests still need a local build, or `OUTAGE_BASE_URL` (`tests/e2e/tour.spec.ts:1-6`, `tests/e2e/share.spec.ts:1-6`) |
| Wikidata outage server | `DISABLE_WIKIDATA=1 SIMULATE_SLOW_BURIALS=Q216344 pnpm start -p 3169`, then `OUTAGE_BASE_URL=http://localhost:3169`. Also `DISABLE_WIKIPEDIA=1`, `DISABLE_OPENSTREETMAP=1` (`lib/data/wikimedia.ts:12-13, 83-86`) |
| Slow big cemetery | `SIMULATE_SLOW_BURIALS=<QID,QID>` makes those burials time out at once (`lib/data/load.ts:41-47`) |
| Read-stone without spending | Locally: `ANTHROPIC_API_KEY=dummy CLAUDE_DAILY_USD_CAP=0`. Every valid upload stops at the cap (503 `daily_cap`) before any Claude call, and the limits never count it, so the upload checks can be fuzzed freely (`lib/readstone/handler.ts:230-286`). With no key at all, the route answers 503 `no_key` before reading the body |
| Short spirit sessions | `/spirit?test-caps=short` or `time`, `/games/evp?test-caps=short` (`lib/spirit/session.ts:26-33`, `lib/games/evp.ts:6-11`) |

## 5. Out of scope

- Attacks on the Vercel, GitHub or Anthropic accounts.
- DoS and load tests, including floods of the data APIs: they would get the shared User-Agent throttled by Wikimedia for everyone (K6).
- Spending the Claude budget: test read-stone locally (section 4); a couple of real reads on prod at most.
