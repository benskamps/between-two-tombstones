# Between Two Tombstones

**Macy's Graveyard Companion.** At any cemetery, it finds the graves with the most interesting stories, walks you through them as a tour, and tells you how those people lived.

Built solo for [Hackyard](https://hackyard.tech) Yard #5, theme "Haunted", Oct 19–23, 2026.

## Prior work

The idea and the written spec (including how the Stamp Kit should turn a headstone photo into a rubbing) were drafted on Oct 18, 2026, before kickoff. No code was written before the build week. Every line in this repo was written after kickoff (Mon Oct 19, 18:00 UTC); the repo itself was created Oct 20, 00:49 UTC. Frameworks and libraries are installed as normal dependencies.

## Data and licenses

- [Wikidata](https://www.wikidata.org) — burials, dates, occupations, grave photos. CC0.
- [Wikipedia](https://en.wikipedia.org) — life summaries. CC BY-SA 4.0, credited on every card.
- [OpenStreetMap](https://www.openstreetmap.org) — cemetery outlines. © OpenStreetMap contributors, ODbL.
- [Find a Grave](https://www.findagrave.com) — outbound links only, built from the Find a Grave IDs Wikidata stores. Nothing is scraped.
