# Between Two Tombstones

**PLAN.md is the only live worklist.** Read it first: readiness contract, decisions, lanes and file ownership. Don't reopen a decision listed there; ask.

## Working rules

- Next.js 16 has breaking changes from older docs. Read `node_modules/next/dist/docs/` before writing framework code. Cache Components is on: cached data uses `'use cache: remote'` + `cacheLife`; runtime data sits inside `<Suspense>`.
- Run `pnpm check` (lint + typecheck + unit tests) and `pnpm build` before every push. CI minutes cost money.
- In this cloud container, Node's `fetch` only uses the proxy with `NODE_USE_ENV_PROXY=1` (set it for `pnpm dev`, `pnpm start` and scripts that reach Wikidata).
- Shapes live in `lib/types.ts`; respect rules in `lib/respect.ts`; site facts and the Wikimedia User-Agent in `lib/site.ts`. Offline demo data in `data/snapshots/` is generated by `scripts/snapshot.mjs`; never edit facts by hand.
- Copy is plain and specific. Errors say what happened and what to do next. No marketing voice.
- Outdoors in October: 48 px tap targets (`.tap`), one dark theme (decision 18: no light theme, no toggle), geolocation requested on tap, never on load.
- Degrade, don't crash: no GPS → search; no network → saved tour; no mic → hide EVP; no speech → captions. Say what was skipped.
- Every loop, retry, poll and timer has a cap. Secrets never go in git, logs or the client bundle.
- New code only (Hackyard rule): nothing written before Oct 19, 18:00 UTC enters this repo.
